# KING-DESIGNER - نسخة التجربة

## 📱 وصف التطبيق
تطبيق تواصل اجتماعي يجمع بين العميل والمصمم والامتيازات حصرية

---

## 🚀 البدء السريع

### المتطلبات:
- Node.js v18+
- npm أو yarn

### خطوات التثبيت:

```bash
# 1. تثبيت المتطلبات
npm install

# 2. التأكد من ملف .env
# الملف موجود بالفعل مع مفاتيح Supabase

# 3. تشغيل التطبيق
npm run dev
```

### الأوامر المتاحة:
```bash
npm run dev        # تشغيل خادم التطوير
npm run build      # بناء النسخة الإنتاجية
npm run preview    # معاينة النسخة المبنية
npm run lint       # فحص الأخطاء
npm run typecheck  # فحص أنواع TypeScript
```

## 📂 هيكل المشروع

### الصفحات الرئيسية:
- **HomePage.tsx** - الصفحة الرئيسية والمنشورات
- **ProfilePage.tsx** - ملف المستخدم الشخصي
- **AuthPage.tsx** - تسجيل الدخول والتسجيل
- **MessagesPage.tsx** - الرسائل المباشرة
- **AdminPage.tsx** - لوحة التحكم
- **ServiceRequestsPage.tsx** - طلبات الخدمات
- **SearchPage.tsx** - البحث والاستكشاف
- **FriendsPage.tsx** - قائمة الأصدقاء
- **NotificationsPage.tsx** - الإشعارات

### السياقات (Context):
- **AuthContext.tsx** - إدارة حالة المصادقة
- **LanguageContext.tsx** - تبديل اللغات (EN/AR)
- **ThemeContext.tsx** - إدارة المواضيع

### المساعدات:
- **helpers.ts** - دوال مساعدة عامة
- **useBrowserNotifications.ts** - إشعارات المتصفح
- **supabase.ts** - إعدادات الاتصال بـ Supabase
- **translations.ts** - جميع النصوص المترجمة

### قاعدة البيانات:
- **migration files** - 25+ ملف ترحيل SQL
  - إنشاء الجداول الأساسية والممتدة
  - سياسات الأمان (RLS)
  - الوظائف والمشغلات
